🚀 راه‌اندازی سریع (۵ دقیقه)

  1. ثبت‌نام در GitHub در سایت github.com با ایمیل خود ثبت‌نام کنید.
  2. ثبت‌نام در Railway به railway.app بروید و با اکانت GitHub وارد شوید.
  3. Deploy پروژه روی Deploy کلیک کنید، GitHub Repository را انتخاب کنید و لینک زیر را وارد کنید:
    github.com/aghabanafshi6122/myprojectt
  4. تنظیم دامنه روی پروژه کلیک کنید → Settings → Generate Domain. اگر پورت خواست، عدد 8080 را وارد کنید.
  5. ورود به پنل در انتهای آدرس، /login را اضافه کنید و رمز پیش‌فرض را وارد کنید.

🎉 تبریک! شما الان یک پنل شخصی ساخت کانفیگ دارید.

💾 ذخیره تنظیمات (پیشنهادی)

اگر می‌خواهید بعد از آپدیت‌های پنل، کانفیگ‌های شما ذخیره بمانند:

  1. کلیک راست روی پروژه در Railway روی پروژه کلیک راست کنید.
  2. Attach Volume روی گزینه Attach Volume کلیک کنید.
  3. مسیر داده در کادر بالا عبارت زیر را وارد کنید:
    /data
  4. ذخیره Enter بزنید و صبر کنید تا Deploy تمام شود.

✅ از این به بعد تنظیمات شما پایدار خواهند ماند!
