🚀 راه‌اندازی سریع (۵ دقیقه)

  1. Fork کردن ریپو روی GitHub دکمه Fork را بزنید تا ریپو به اکانت خودتان منتقل شود.
  2. دیپلوی روی Railway به railway.app بروید → New Project → Deploy from GitHub Repo → ریپوی Fork شده را انتخاب کنید. Railway به‌طور خودکار ساخت ایمیج را شروع می‌کند.
  3. ساخت ادمین (پیشنهادی) در تب Variables پروژه Railway این دو متغیر را اضافه کنید:
    SUDO_USERNAME=admin SUDO_PASSWORD=YourStrongPass123!
  4. (اختیاری) فعال‌سازی PostgreSQL پلاگین Postgres را در Railway اضافه کنید و آدرس اتصال را به‌عنوان متغیر تنظیم کنید:
    SQLALCHEMY_DATABASE_URL=postgresql://user:pass@host:port/dbname
  5. ورود به پنل بعد از اتمام Build (حدود ۳ تا ۵ دقیقه)، دامنه Railway را باز کنید:
    https://your-app.up.railway.app/dashboard/
    با SUDO_USERNAME و SUDO_PASSWORD وارد شوید.
🎉 تبریک! پنل Marzban شما روی Railway آماده است.

⚠️ نکات مهم

🔐 TLS: خود Railway لایه TLS را مدیریت می‌کند. نیازی به تنظیم گواهی SSL داخل کانتینر نیست.
💾 پایداری داده: فایل‌سیستم Railway موقتی است. برای استفاده جدی از PostgreSQL و در صورت نیاز Volume استفاده کنید.
📌 نسخه Marzban: با تغییر MARZBAN_REF در railway.json می‌توانید نسخه خاصی را پین کنید (مثلاً v0.8.0).
🔌 پورت: Railway خودش $PORT را تزریق می‌کند. آن را دستی تنظیم نکنید.
